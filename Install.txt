================================================================================
YABB - Yet Another BTRFS Backup
Installation Guide
================================================================================

REQUIREMENTS
------------
- Linux with BTRFS filesystems (source and destination must both be BTRFS)
- Root access (sudo) for backup operations
- Bash 5.2 or newer (for automatic installer)
- btrfs-progs 5.14 or newer
- Standard tools: pv, flock, setfattr, getfattr, curl

Most Linux distributions include these tools. On Debian/Ubuntu:
  sudo apt install btrfs-progs pv attr curl

On Fedora:
  sudo dnf install btrfs-progs pv attr curl

On Arch Linux:
  sudo pacman -S btrfs-progs pv attr curl


================================================================================
OPTION A: AUTOMATIC INSTALLATION (Recommended)
================================================================================

The easiest way to install YABB is using the automatic installer script.
This downloads the latest release, verifies checksums, and installs:
  - Binary and scripts to /opt/yabb/
  - Configuration to /etc/yabb.toml (if not already present)
  - Shell completions to system locations (bash, zsh, fish)
  - Systemd service files to /etc/systemd/system/

The installer is CONSERVATIVE: it never overwrites existing files.

1. Run the installer:

   curl -fsSL --proto '=https' --tlsv1.2 https://raw.githubusercontent.com/aryonoco/yabb/main/scripts/install.sh | sudo bash

   Or download and inspect first:

   curl -fsSL --proto '=https' --tlsv1.2 https://raw.githubusercontent.com/aryonoco/yabb/main/scripts/install.sh -o install.sh
   less install.sh  # Review the script
   sudo bash install.sh

2. Edit your configuration file:

   sudo nano /etc/yabb.toml    # or your preferred editor

   Update the [paths] section with your actual directories:
   - src_dir: The directory you want to back up (must be on BTRFS)
   - dst_dir: Where to send snapshots (must be on BTRFS)
   - snapshot_dir: Where to store local snapshots (must be on BTRFS)

3. Verify the installation:

   /opt/yabb/yabb --help

4. Enable automated backups and updates:

   sudo systemctl enable --now yabb.timer yabb-update.timer


UPDATING YABB
-------------
To update to the latest version:

   sudo /opt/yabb/scripts/install.sh --force

Or use the systemd timer for automatic weekly updates (see SYSTEMD section below).


UNINSTALLING YABB
-----------------
Remove YABB but keep configuration:

   sudo /opt/yabb/scripts/install.sh --remove

Remove YABB and all configuration:

   sudo /opt/yabb/scripts/install.sh --remove --purge --force


================================================================================
OPTION B: MANUAL USER INSTALLATION (From Tarball)
================================================================================

This installs yabb for your user only, without modifying system directories.
Use this if you downloaded the release tarball manually.

1. Extract and install the binary:

   zstd -d -c yabb-*.tar.zst | tar -xf -
   mkdir -p ~/.local/bin
   cp yabb-*/yabb ~/.local/bin/
   chmod +x ~/.local/bin/yabb

2. Verify ~/.local/bin is in your PATH:

   echo $PATH | grep -q "$HOME/.local/bin" && echo "OK" || echo "Not in PATH"

   On Debian, Ubuntu, and Fedora, ~/.local/bin is automatically added to PATH
   when it exists. If it's not in your PATH:

   # For bash, add to ~/.bashrc:
   export PATH="$HOME/.local/bin:$PATH"

   # For zsh, add to ~/.zshrc:
   export PATH="$HOME/.local/bin:$PATH"

   # For fish, run:
   fish_add_path ~/.local/bin

   NOTE: Arch Linux does NOT add ~/.local/bin to PATH by default.
   You must add it manually as shown above.

3. Verify the installation:

   yabb --help

4. Create your configuration file:

   mkdir -p ~/.config/yabb
   cp yabb-*/yabb.conf ~/.config/yabb/yabb.toml
   nano ~/.config/yabb/yabb.toml    # or your preferred editor

   Update the [paths] section with your actual directories:
   - src_dir: The directory you want to back up (must be on BTRFS)
   - dst_dir: Where to send snapshots (must be on BTRFS)
   - snapshot_dir: Where to store local snapshots (must be on BTRFS)


SHELL COMPLETIONS (User Installation)
-------------------------------------
For Bash (add to ~/.bashrc):
   mkdir -p ~/.local/share/bash-completion/completions
   cp yabb-*/shell_completions/yabb.bash ~/.local/share/bash-completion/completions/yabb
   # Restart your shell or run: source ~/.local/share/bash-completion/completions/yabb

For Zsh (add to ~/.zshrc):
   mkdir -p ~/.local/share/zsh/site-functions
   cp yabb-*/shell_completions/yabb.zsh ~/.local/share/zsh/site-functions/_yabb
   # Restart your shell or run: exec zsh

For Fish:
   mkdir -p ~/.config/fish/completions
   cp yabb-*/shell_completions/yabb.fish ~/.config/fish/completions/yabb.fish
   # Restart your shell or run: exec fish


================================================================================
OPTION C: MANUAL SYSTEM-WIDE INSTALLATION (From Tarball)
================================================================================

This installs yabb for all users on the system.

1. Extract and install to /opt:

   zstd -d -c yabb-*.tar.zst | tar -xf -
   sudo mkdir -p /opt/yabb
   sudo cp yabb-*/yabb /opt/yabb/
   sudo chmod +x /opt/yabb/yabb

2. Create symlink (or add to PATH):

   sudo ln -sf /opt/yabb/yabb /usr/local/bin/yabb

   Or add to system PATH (create a profile script):

   echo 'export PATH="/opt/yabb:$PATH"' | sudo tee /etc/profile.d/yabb.sh
   sudo chmod +x /etc/profile.d/yabb.sh

   Log out and back in, or run: source /etc/profile.d/yabb.sh

3. Verify the installation:

   yabb --help

4. Create the system configuration:

   sudo cp yabb-*/yabb.conf /etc/yabb.toml
   sudo nano /etc/yabb.toml    # or your preferred editor

   Update the [paths] section with your actual directories.


SHELL COMPLETIONS (System-Wide)
-------------------------------
For Bash:
   sudo cp yabb-*/shell_completions/yabb.bash /etc/bash_completion.d/yabb
   # Restart your shell or run: source /etc/bash_completion.d/yabb

For Zsh:
   sudo mkdir -p /usr/local/share/zsh/site-functions
   sudo cp yabb-*/shell_completions/yabb.zsh /usr/local/share/zsh/site-functions/_yabb
   # Restart your shell or run: exec zsh

For Fish:
   sudo mkdir -p /usr/share/fish/vendor_completions.d
   sudo cp yabb-*/shell_completions/yabb.fish /usr/share/fish/vendor_completions.d/yabb.fish
   # Restart your shell or run: exec fish


================================================================================
CONFIGURATION
================================================================================

YABB searches for configuration in this order:
1. Path specified with --configPath
2. /etc/yabb.toml (system-wide)
3. ~/.config/yabb/yabb.toml (user)

The configuration file uses TOML format. Key sections:

[paths]
  src_dir = "/data"           # Source directory to back up
  dst_dir = "/backup"         # Destination for snapshots
  snapshot_dir = "/snapshots" # Local snapshot storage

[retention]
  hourly = 24    # Keep 24 hourly snapshots
  daily = 7      # Keep 7 daily snapshots
  weekly = 4     # Keep 4 weekly snapshots
  monthly = 6    # Keep 6 monthly snapshots
  yearly = 2     # Keep 2 yearly snapshots

[compression]
  algorithm = "zstd"  # Options: zstd, zlib, lzo
  level = 3           # 1-15 for zstd; 1-9 for zlib/lzo


================================================================================
QUICK START
================================================================================

1. Validate your configuration:
   sudo yabb validate

2. Check the current status:
   sudo yabb status

3. See what a backup would do (dry run):
   sudo yabb run --dryRun

4. Run your first backup:
   sudo yabb run

5. Check health of your backup chain:
   sudo yabb health


================================================================================
SYSTEMD AUTOMATION (Recommended)
================================================================================

YABB includes hardened systemd service files for automated backups and updates.
These use modern systemd 257 features for security hardening.

ENABLING THE TIMERS
-------------------
If you used the automatic installer (Option A), the systemd service files are
ALREADY installed to /etc/systemd/system/. Just enable the timers:

   sudo systemctl enable --now yabb.timer yabb-update.timer

If you installed from tarball (Option B/C), copy the service files first:

   sudo cp yabb-*/scripts/yabb.service /etc/systemd/system/
   sudo cp yabb-*/scripts/yabb.timer /etc/systemd/system/
   sudo cp yabb-*/scripts/yabb-update.service /etc/systemd/system/
   sudo cp yabb-*/scripts/yabb-update.timer /etc/systemd/system/
   sudo mkdir -p /etc/yabb
   sudo cp yabb-*/scripts/yabb-update.conf /etc/yabb/update.conf
   sudo systemctl daemon-reload
   sudo systemctl enable --now yabb.timer yabb-update.timer


WHAT THE SERVICES DO
--------------------
yabb.timer / yabb.service:
  - Runs daily BTRFS backup
  - Low CPU/IO priority to avoid impacting other work
  - Comprehensive security hardening

yabb-update.timer / yabb-update.service:
  - Runs weekly to check for and install YABB updates
  - Network access limited to GitHub only
  - Verifies SHA256 checksums before installing


CONFIGURING BACKUP PATHS
------------------------
The yabb.service needs read/write access to your BTRFS paths.
Create a drop-in file to configure these:

   sudo mkdir -p /etc/systemd/system/yabb.service.d
   sudo nano /etc/systemd/system/yabb.service.d/paths.conf

Add your paths (adjust to match your /etc/yabb.toml):

   [Service]
   ReadWritePaths=/data /backup /snapshots

Then reload and restart:

   sudo systemctl daemon-reload
   sudo systemctl restart yabb.service


CHECKING STATUS
---------------
View timer status:
   systemctl list-timers yabb*

View service logs:
   journalctl -u yabb.service
   journalctl -u yabb-update.service

Run backup manually:
   sudo systemctl start yabb.service

Run update manually:
   sudo systemctl start yabb-update.service

Check security score:
   systemd-analyze security yabb.service
   systemd-analyze security yabb-update.service


================================================================================
TROUBLESHOOTING
================================================================================

- "Permission denied": Run with sudo
- "Not a btrfs filesystem": Ensure all paths are on BTRFS volumes
- "No parent snapshot": First run creates a full snapshot (expected)
- "Config file not found": Create config at ~/.config/yabb/yabb.toml or /etc/yabb.toml
- "Bash version too old": Requires Bash 5.2+ for automatic installer
- Check logs: journalctl -u yabb.service (if using systemd)
